SIGNATURE PAIRING Warmth and depth. Quiet confidence. Use Crimson Maroon
as Xogul's recognisable emotional anchor. Use Warm Ivory to soften the

brand-led surfaces when ivory can be used instead. CORE APPLICATION RULE

restrained: one dominant colour, one supporting surface, and minimal
